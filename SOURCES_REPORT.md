Nothing is sent anywhere by the book. Answers, stars, progress and settings are stored in the reader’s own browser (`localStorage`, always inside try/catch) and can be downloaded as a text file. YouTube is loaded only after the reader presses the load button, from `youtube-nocookie.com`. **When the book is opened from `file://` YouTube may refuse to play (error 153) because there is no web origin; host the folder on a web server or GitHub Pages.**
